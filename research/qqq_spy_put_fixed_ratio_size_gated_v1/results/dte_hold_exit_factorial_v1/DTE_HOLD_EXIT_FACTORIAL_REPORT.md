## 重要限制與稽核說明

- 原回放步驟成功完成了所有 20 個 DTE/相位設定；12 種政策的 summary 資料存在 Actions 輸出記錄。最後彙總器因 Python 排序錯誤 (`TypeError: '<' not supported between instances of 'int' and 'str'`) 而失敗，所以完整 per-trade/逐年資料沒有提交。
- 此重建報告使用 Actions 記錄內每個設定的政策彙總值，不包含原始 `trade_episodes.csv`；因此無法據此稽核逐年損益集中度、實際持倉同時重疊曲線或峰值指派義務。這些欄位沒有從 log summary 中推算或虛構。
- 歷史 EOD 報價是報價側估算，不是已驗證成交。資料檔的 hash/byte pin 只能固定檔案內容，不能獨立證明原始資料來源是交易所/OPRA 真實報價。
- 沒有帳戶現金、保證金、指派資金、強制平倉、融資、稅項、複利或 TAIL 保險成本模型。這些結果不證明 $100,000 NAV 可以承受策略。
- DTE60 的每相位進場數中位數約 115；DTE20/30 約 195，DTE45 約 176。DTE 水平會影響可選到合格共同到期日的頻率，故 DTE 的年度影響包含交易機會數量效應。
