# Preliminary result archive — NOT A VALID CONTINUOUS-HEDGE RANKING

These files preserve the first exploratory run before the put premium budget was corrected. In that version, the model allocated 2% of NAV to every new debit-put spread rather than limiting gross premium spend annually. The replay consumed the 58% cash reserve by around 2013; the ledger then recorded thousands of no-capacity entries. Consequently, the preliminary put/combined CAGR and MaxDD are useful only as evidence that per-roll budget compounding is structurally unsafe. Do not use these files to rank strategies or infer that a well-budgeted put hedge worsens drawdown.

The corrected run changes the debit-put budget to 2% annualized gross premium spend, prorated by planned exposure days per cycle. Source hashes and original files are retained unchanged below.
